📖 Довідник команд Git

Командний проєкт веб-студії | Спринт 1

🖥️ Локальна робота

git init

Ініціалізує новий репозиторій у поточній папці.

git status

Показує стан файлів: які змінені, які додані до індексу.

git add .

Додає всі змінені файли до індексу (staging area).

git commit -m "Повідомлення"

Зберігає зміни з коментарем у локальний репозиторій.

git log --oneline

Показує скорочену історію комітів.

🌿 Робота з гілками

git branch назва-гілки

Створює нову гілку.

git checkout -b назва-гілки

Створює нову гілку і одразу переходить на неї.

git merge назва-гілки

Зливає вказану гілку в поточну.

git branch -d назва-гілки

Видаляє гілку після злиття.

git branch -a

Показує всі гілки, включно з віддаленими.

☁️ Робота з GitHub

git clone URL

Клонує віддалений репозиторій на локальний комп'ютер.

git push origin назва-гілки

Відправляє гілку на GitHub.

git pull origin main

Завантажує останні зміни з GitHub у локальний репозиторій.

git remote -v

Показує список віддалених репозиторіїв.

git fetch

Завантажує зміни з GitHub, але не зливає їх автоматично.
