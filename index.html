Довідник команд Git

Локальна робота

git init - створити репозиторій

git add . - додати файли

git commit -m "текст" - зберегти зміни

Робота з гілками

git branch - показати гілки

git checkout -b назва - створити гілку

git merge назва - злити гілку

Робота з GitHub

git clone URL - скопіювати репозиторій

git push - відправити на GitHub

git pull - завантажити зміни
